# chordTrainer

Guitar chords, scales and practice tools, with a left-handed and right-handed switch.

- Chord finder for every note and 16 chord types
- My chords: save the chords you are learning and quiz yourself
- Fretboard with 24 scales (including Egyptian and Middle Eastern ones), chord notes and tunings
- Keys, progressions, circle of fifths and a capo helper
- Chord change trainer with a metronome
- Songs with the chords written above the words
- Tuning reference tones
- Four colour themes (light, blue, black, sand) plus one that matches your device

The page is a single `index.html`. To change it, edit the files in `src/` and run `python3 build.py`.
